# ZIMGo: Unlock your life
### https://zimgo.vercel.app/

ZIMGo is a webpage made to unlock your personal and work devices. Here, you can play games, browse another website, use our AI, watch YouTube videos or stream TV channels in real time.

## Setup your APIs
### ZimTube
ZimTube uses a paid API key that is private for the original ZIMGo project. If you want to enable ZimTube on your fork, get your own API key on Google Developer Console called "YouTube v3". Paste it on the files located in /app/api/youtube, on the API key variable.
